Put your cover image in this folder and name it one of:

  cover.jpg
  cover.jpeg
  cover.png

The book will automatically detect it and use it as the front cover art.
If no file is found here, a hand-styled gold-on-leather cover is used instead —
so the site always looks finished even before you add the real image.

Recommended: a portrait-ish image, at least 800px on the short side,
so it doesn't look stretched inside the cover frame.
